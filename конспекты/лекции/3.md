# Оптимизация серверной части веб-приложений

## Основные понятия

<strong>Мерило производительности</strong> - количество обрабатываемых запросов в секунду и скорость их выполнения

<strong>Устойчивость к отказам</strong> - способность системы при отказе одного или нескольких серверов к продолжению работы в рамках требуемых параметров

<strong>Устойчивыми к катастрофам</strong> считаются системы, имеющие полное дублирующее резервирование и способные без сильной просадки работать при полном отказе одного из дата-центров

<strong>Масштабируемость</strong> - пул возможностей для увеличения RPS (кол-во обрабатываемых запросов в секунду)

### Масштабирование бывает:

1. <strong>Вертикальное</strong> - рост объема ресурсов при сохранении количества сущностей

2. <strong>Горизонтальное</strong> - рост количества сущностей
