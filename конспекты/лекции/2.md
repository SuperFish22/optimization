# Лекция 2. 

## Виды конкурентов:
1. Прямые конкуренты - люди, компании, продукты, услуги - предоствляющие идентичные услуги
2. Косвенные конкуренты - компании, предоставляющие похожие, но не идентичные услуги
3. Подменные - предполагают различные услуги, могут выступать взаимозаменяемыми

## Виды конкуренций:
1. Прямая
2. Непрямая
3. Подменная

Моя ниша - майнкрафт-сервер.

### Примеры конкурентов:
1. https://hypixel.net/ - прямой
2. https://www.cubecraft.net/ - прямой
3. https://mineplex.com/ - прямой
4. https://playhive.com/ - прямой
5. https://hytale.com/ - непрямой

### Матрица позиционирования (на примере музыкантов)
1. Основные приколы этого чувака
2. Популярность - количество прослушиваний; аудитория
3. Расчеты. Два критерия: по горизонтали - возраст аудитории (по убыванию, в точке 0 - 20 лет); вертикаль - популярность по возрастанию (5000 в точке 0)

### SWOT-анализ:
1. Сильные стороны
2. Слабые стороны
3. Возможности
4. Угрозы

### SWOT-анализ, для чего используется:
1. Анализ точек продаж
2. Анализ филиалов
3. Анализ направлений продукта
4. Анализ направлений бизнеса
