# Лекция 1.

## Определения

*Web-приложение* - приложение, разработанное по архитектуре "клиент-сервер", использующее в качестве клиента веб-браузер и работающее с использованием протокола HTTP на стороне веб-браузера

*Текстовый редактор* - программа для редактирования форматов, которые рендерятся в браузере.

*Движок* - совокупность специализированных программ для ускорения разработки

*Веб-стандарты* - открытые, незащищенные какими-либо патентами спецификации и рекомендации W3C

*W3C* - Консорциум Всемирной Паутины (WWW Consortium) - организация, разрабатывающая и внедряющая технологические стандарты для сети Интернет

*WaSP* - рабочая группа по стандартизации Web (Web Standarts Project) - добровольческая организация, созданная независимой группой веб-разработчиков и активно пропагандирующая современные концепции веб-технологий

*Макет (шаблон сайта)* - графическое представление дизайна сайта

*Верстка* - процесс формирования страниц (макета) путем компоновки текстовых, графических и прочих элементов.

*Верстка* - создание кода страницы с использованием языка HTML и их оформление с помощью CSS

*Язык программирования* представляет собой знаковую систему, которая предназначена для описания алгоритмов

*CMS* - система управления сайтом (Content management system, движок)

*CMS* - специальная платформа, ПО, позволяющее создавать и поддерживать веб-сайты различных уровней сложности

*Тематический индекс цитирования (тИЦ)* - технология поисковой машины "Яндекс", заключающаяся в определении авторитетности интернет-ресурсов с учетом качественной характеристики - ссылок на них с других сайтов. тИЦ рассчитывается по специально разработанному алгоритму, в котором особое значение придается тематической близости ресурса и ссылающихся на него сайтов. Данный показатель в первую очередь используется для определения порядка расположения ресурсов в рубриках каталога "Яндекс"

*Хостинг* - услуга по предоставлению дискового пространства для физического размещения необходимой информации, файлов веб-сайта на сервере, постоянно находящегося в сети интернет, на котором запущено ПО, необходимое для обработки запрашиваемой информации к веб-серверу

*Виртуальный выделенный сервер* подразумевает:
1. Веб-прилы размещаются на одном физическом сервере
2. Каждый сервер независим от других
3. Имеет свой определенный лимит, отведенный ему программой

*SEO (Search Engines Optimization)* - комплекс мероприятий, направленных на повышение позиций интернет-сайта в результатах поисковой системы по некоторому списку популярных сайтов

### Типы сайтов
1. Личный сайт
2. Бизнес-сайт
3. Сайты E-Commerce: инет-магазин; инет-магазин с системой электронных платежей; обменные пункты
4. Инфо порталы: новостной портал, тематические порталы, доски объявлений, файловые архивы, вики
5. Промо-сайты
6. Инет-общение
7. Сайты спецназначения: Wap-сайты, поисковая система, каталоги и рубрикаторы, рейтинги сайтов и системы статистики, почтовые сайты.

*Wap-сайт* - сайт, на который можно зайти с мобильного телефона

*Поисковая система* - вид сайта, с помощью которого посетитель может найти интересующую его инфу, введя в спецполе запрос и получив на него список сайтов, соответствующих запросу

### Каталоги и рубрикаторы:
Каталог - сайт, содержащий систематизированный перечень сайтов сети, компаний, товаров, услуг и т.п.

### Виды каталогов:

1. Общетематические
2. Тематические
3. Специализированные

### Требования к верстке:

1. Кроссбраузерность
2. Гибкость верстки
3. Быстрота обработки кода браузером
4. Валидность
5. Семантическая корректность

*Техническое задание* - это документ, в котором детально описываются основные составляющие и требования к будущему сайту

### ТЗ включает:

1. Тип сайта
2. Функционал сайта
3. Стиль дизайна
4. Структура сайта
5. Структура страниц

## Этапы разработки веб-сайта:
1. Подготовительный
2. Разработка макета
3. Верстка
4. Программирование установка на CMS
5. Наполнение контентом
6. Публикация сайта в интернете
7. Раскрутка сайта
8. Администрирование (поддержка) сайта

### Подготовительный этап:

1. Определение цели сайта
2. Определение целевой аудитории
3. Выяснение ожидаемой информации
4. Выбор технологического и программного обеспечения
5. Планирование навигации

## Виды верстки:
1. Табличная. Используется обычная таблица с невидимой границей
2. Блочная. Используются слои (блоки) для создания базового шаблона страницы, добавляется нужное количество блоков, которые как слои накладываются друг на друга

### Достоинства табличной верстки:
1. Простота и быстрота верстки
2. Корректное отображение в различных браузерах, одинаковый вид во всех браузерах

### Недостатки табличной верстки:
1. Долгая загрузка
2. Громоздкий код
3. Плохая индексация поисковыми системами
4. Нет разделения содержимого и оформления
5. Несоответствие стандартам

### Достоинства блочной верстки:
1. Компактный код, небольшой вес страниц
2. Отличная индексация поисковыми системами
3. Слои можно накладывать друг на друга
4. Быстрая загрузка страниц

### Недостатки блочной верстки:
1. Верстка сложная
2. Трудно обеспечить одинаковый вид во всех браузерах
3. При уменьшении разрешения экрана/браузера блоки съезжают друг на друга
